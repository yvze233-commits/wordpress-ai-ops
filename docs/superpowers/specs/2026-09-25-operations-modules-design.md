# WordPress AI Ops 运营模块设计

## 目标

把当前仅有列表展示的后台模块改造成可操作的运营工作台：资产可维护，内容批次可执行，文章可审核和写入草稿，WordPress 连接可测试，导航能显示待处理状态。

## 约束

- 保持现有 Laravel、SQLite、Eloquent、Blade 和 JSON 响应模式。
- 敏感配置继续使用加密字段；页面不回显密码或 API key。
- 删除采用停用或受保护删除，已有文章引用的资产不能硬删除。
- WordPress 只写草稿，不能由后台操作直接公开发布。
- 页面和 JSON API 使用同一组控制器动作，便于浏览器脚本调用。

## 功能边界

### 资产

知识库支持新建、编辑、启停、Markdown/TXT 导入、文档分片、默认库标记和文档状态查看。图片库支持新建、批量上传、标题/备注/关键词/场景/alt/版权状态编辑、预览、启停和使用次数。标题库支持单条添加、批量粘贴导入、分类、优先级、启停和已使用状态。热点来源支持 RSS、JSON、HTML 配置、启停、暂停和立即抓取。

### 内容流程

内容批次支持立即创建、指定日期创建、详情状态统计、失败项重试和单篇详情。审核页支持状态筛选、证据/来源/图片检查、批准、人工复核、重试生成和写入 WordPress 草稿。发布连接支持编辑、REST 测试、最近状态和草稿回读。

### 导航

侧边栏保留工作台和资产配置分组；每个入口显示待处理数量或最近错误，移动端保持可用。

## 数据与状态

优先复用现有模型和服务。新增字段仅在无法表达“默认库、软删除、抓取结果”时通过前向迁移增加。所有状态变更使用现有 `ContentStateTransition` 或明确的模型状态枚举，并写入审计事件。

## 验收标准

- 每个资产模块都有可提交的表单、验证失败反馈和成功后列表回读。
- 知识库导入后能看到文档和分片数；默认库会参与文章证据检索。
- 图片必须保存非空 alt，发布前能显示预览和版权状态。
- 标题和热点候选能进入批次选择，并且已使用标题不重复选择。
- 批次详情能看到每篇文章的生成、审核和发布状态，失败项有重试入口。
- 审核详情能看到二段审核结果、来源、证据、图片 alt 和发布按钮。
- WordPress 连接测试能区分 URL、认证、权限和 REST 响应错误。
- Feature 测试覆盖成功、验证失败、重复和状态流转路径。
